Processing time sums successful photos: image decoding, logo decoding/scaling/overlay, text rendering and PNG disk write (including fsync). Uploads, queue time and ZIP creation are excluded. Processing throughput = completed photos ÷ processing time. Batch elapsed includes uploads, failed attempts and communication. This is a sequential batch test, not a concurrency test or a maximum-capacity estimate.
